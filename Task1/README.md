# Утечка данных

Риски: Утечка персональных данных клиентов и собственников. Утечка финансовой отчетности. Утечка административных доступов (логины/пароли/токены/сертификаты).

Возможные последствия: Штрафы за нарушение ФЗ-152, репутационный ущерб, мошенничество с клиентскими данными. Раскрытие финансовых возможностей компании. Нанесение вреда компании, промышленный шпионаж.

# Потеря данных

Риски: Удаление данных объектов недвижимости (client-mart-db, client-tour-db). Сбои в хранилище данных, S3). Отказ платежных систем (потеря транзакций).

Возможные последствия: Нарушение бизнес-процессов (сделки, отчетность). Финансовые потери из-за недоступности данных.

# Искажение данных

Риски: Подмена данных о собственниках (CRM, tenant-core-db). Фальсификация каталога объектов (client-mart-app). Ошибки в интеграциях (СМЭВ, платежные системы).

Возможные последствия: Юридические конфликты из-за некорректных записей.
Финансовые потери (например, ошибочные платежи).

# Некачественные данные

Риски: Дублирование клиентов в crm-db. Некорректная информация об объектах (площадь, статус). Ошибочные аналитические отчеты (на основе DWH).

Возможные последствия: Принятие неверных бизнес-решений. Недоверие клиентов (например, из-за ошибок в договорах).

# Обесценивание данных

Риски: Устаревшие каталоги объектов (проданные, но не исключенные из системы).
Некорректные аналитические модели (на основе старых данных из DWH).
Хранение избыточных данных (например, неактуальные логи).

Возможные последствия: Затраты на хранение бесполезных данных.
Ошибки в прогнозировании продаж.


PS Оценка каждому риску дана на диаграмме. Линии покрашены в соответствующий цвет. легенда прилагается.
